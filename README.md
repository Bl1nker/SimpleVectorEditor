# Векторный графический редактор ломаных линий

Простой векторный редактор на **C# и WPF**, позволяющий создавать, редактировать и сохранять ломаные линии (полилинии).

## 📌 Возможности

- Рисование ломаных линий с произвольным числом узлов
- Завершение рисования по нажатию **Enter**, **Пробела** или **ПКМ**
- Перетаскивание отдельных узлов линии
- Добавление новых узлов по **двойному клику** по сегменту
- Перемещение **всей линии целиком** (клик по линии, но не по узлу)
- Настройка цвета и толщины каждой линии отдельно
- Удаление выделенной линии (клавиша **Delete** или кнопка)
- Сохранение и загрузка рабочей области в **JSON-файл**

## 📦 Сборка из исходников

### Требования
- .NET SDK 6.0 или выше ([скачать](https://dotnet.microsoft.com/download))
- Visual Studio 2022 (или любая другая IDE, поддерживающая .NET)
- **NuGet-пакеты**: `Newtonsoft.Json` (восстанавливаются автоматически при сборке)

### Инструкция
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Bl1nker/SimpleVectorEditor
2. Откройте решение VectorEditor.sln в Visual Studio.
3. Выберите конфигурацию Release.
4. Соберите проект: Build → Build Solution.
5. Запустите приложение.

## ▶️ Запуск без сборки
Готовую версию приложения можно скачать и запустить без установки IDE. Для этого распакуйте архив VectorEditor_App.zip и запустите VectorEditor.exe.
